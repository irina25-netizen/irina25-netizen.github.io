Политика конфиденциальности

Последнее обновление: 19 октября 2026 г.

Приложение «Личный ассистент-ментор» — частный инструмент одного пользователя (его владельца). Оно работает на личном сервере владельца и не предназначено для других людей.

Какие данные Google использует приложение

Только данные собственного аккаунта владельца, и только после его согласия на экране доступа Google:

  • Google Таблицы — чтение и обновление таблиц целей и дневника владельца;
  • Google Документы и Google Диск — чтение и обновление рабочих документов и файлов владельца;
  • Google Календарь — чтение и создание событий владельца;
  • Google Контакты — только чтение.

Как используются данные

Данные используются только для работы личного ассистента владельца: напоминания, ежедневные сверки, ведение целей и записей. Для формирования ответов нужные фрагменты данных могут передаваться провайдеру языковой модели, который владелец использует в своём ассистенте, только для обработки запроса владельца. Данные не продаются, не передаются третьим лицам для рекламы или иных целей и не используются для обучения моделей общего назначения. Использование информации, полученной от Google API, соответствует Политике Google в отношении пользовательских данных API (Google API Services User Data Policy), включая требования ограниченного использования.

Хранение и защита

Токен доступа хранится в закрытом файле на сервере владельца. Данные Google не копируются в общедоступные места. Владелец может в любой момент отозвать доступ на странице аккаунта Google: myaccount.google.com/permissions.

Privacy Policy

Last updated: October 19, 2026.

"Personal Mentor Assistant" is a private, single-user tool. It runs on its owner's own private server and is not intended for other people.

Google data the app uses

Only data in the owner's own Google account, and only after the owner grants consent on the Google access screen:

  • Google Sheets — reading and updating the owner's goal and diary spreadsheets;
  • Google Docs and Google Drive — reading and updating the owner's working documents and files;
  • Google Calendar — reading and creating the owner's events;
  • Google Contacts — read-only.

How the data is used

The data is used only to operate the owner's personal assistant: reminders, daily check-ins, and keeping goals and records. To produce replies, relevant pieces of data may be sent to the language-model provider that the owner uses in the assistant, solely to process the owner's request. The data is not sold, not shared with third parties for advertising or other purposes, and not used to train general-purpose models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The access token is stored in a private file on the owner's server. Google data is not copied to publicly accessible places. The owner can revoke access at any time at myaccount.google.com/permissions.
